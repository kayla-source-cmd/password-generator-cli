# Password Generator CLI

A simple Python command-line application that generates random passwords based on the length entered by the user.

## Features
- Generates random passwords.
- Allows users to choose password length.
- Includes letters, numbers, and symbols.
- Rejects invalid password lengths.

## Technologies
- Python 3
- Random module
- String module

## How to Run

```bash
python3 password_generator.py
```
